# Загрузка MB WORLD 3D на GitHub Pages с iPhone

Нужно: 30 архивов MBW-01.zip … MBW-30.zip + файл pages.yml. Распаковывать ничего не нужно.

## Вариант A — Safari (без приложений)
1. Откройте github.com → ваш репозиторий (или создайте новый: «+» → New repository, Public).
2. **Add file → Upload files**. Из «Файлы» (iCloud/«На iPhone») выберите архивы.
   - GitHub принимает до 25 МБ на файл и ~100 файлов за раз — наши архивы по ~19,8 МБ, поэтому проходят.
   - Загружайте порциями по 5–10 архивов (при слабой сети надёжнее). Каждую порцию завершайте **Commit changes**.
3. Файл workflow: **Add file → Create new file**, в поле имени введите
   `.github/workflows/pages.yml` (косые черты создадут папки), вставьте всё содержимое pages.yml
   (откройте файл в «Файлах» → выделить всё → скопировать) → **Commit changes**.
4. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
5. Вкладка **Actions** → «Deploy MB WORLD 3D» → **Run workflow** (запустится и сам после коммита в main).
6. После зелёной галочки адрес игры: `https://<ваш-логин>.github.io/<репозиторий>/`

## Вариант B — Working Copy (удобнее для 30 файлов)
1. Клонируйте/создайте репозиторий в Working Copy.
2. Repository → «+» → Import files → выберите все 30 ZIP (в корень репозитория, **не распаковывать**).
3. Создайте файл `.github/workflows/pages.yml` (New File, путь с папками) и вставьте содержимое.
4. Commit → Push. Дальше шаги 4–6 из варианта A.

## Проверка и если что-то не так
- Workflow сам проверит: наличие всех 30 архивов, целостность ZIP, отсутствие дубликатов, склейку .partNN и SHA256 всех 298 файлов. При ошибке в логе будет понятное сообщение (например, «Missing archive: MBW-17.zip»).
- Проверить загрузку архивов вручную можно по MBW-ARCHIVES.sha256 (суммы самих ZIP).
- Архивы должны лежать именно в корне репозитория (рядом с папкой .github).
- Не переименовывайте ZIP и не добавляйте в репозиторий другие файлы MBW-*.zip (старые 20 архивов удалите!).
